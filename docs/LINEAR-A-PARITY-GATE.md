# Linear A parity gate — pre-expert target

Date: 2026-10-06

The Byblos corpus is being brought to parity with the Linear A project in **method, provenance control, reproducibility, uncertainty handling, rights discipline, documentation, and AI-skill behavior**. Parity does not mean equal surviving evidence or an invented equality of corpus size.

## Closure rule

Every tractable gap must end in one of these states:

1. **resolved** — supported by attributable, inspectable evidence;
2. **excluded/deferred by scholarly scope** — with an explicit rationale and evidence trail;
3. **rights/access blocked** — the needed edition, plate, image, transcription, encoding, or provider material cannot lawfully be inspected or redistributed at the required level;
4. **expert-only** — a genuine epigraphic judgment requires independent specialist review after the pre-expert evidence packet is complete.

Unknown data must never be synthesized merely to pass a gate.

## Current parity assessment

### Engineering / research-control layer
Substantially present: catalogue, source registry, coverage ledger, provenance model, admission policy, evidence ledger, external crosswalk, reproducible audits, exports, review packets, CI validation, contribution workflow, rights documentation, and corpus-specific AI skill.

### Evidence layer still below target
- 14 core labels have no verified complete sequence.
- Core object identities are not independently established.
- BYB-G lacks a canonical surface inventory because the evidence is column-based and partly uncertain.
- The 43 OCBI rows remain provider mappings rather than independently verified archaeological identities.
- Dunand 1945 and the 1978 article/plates still require lawful edition-level collation for sequence work.
- Independent specialist approval is zero and must remain zero until a real reviewer acts.

## Non-rights work to exhaust before declaring the rights wall

- Complete systematic bibliography/search dispositions.
- Reconcile corpus-count denominators and explicitly preserve incompatible units.
- Resolve or disposition every external crosswalk row.
- Resolve object/surface identities wherever lawful public evidence supports them.
- Separate bibliographic disagreements from evidence-access blockers.
- Exhaust public metadata and lawful primary witnesses before requesting restricted material.
- Produce a record-by-record handoff stating exactly what evidence would close each remaining gate.

## Rights wall

Rights/access is a legitimate terminal pre-expert blocker only where the missing claim requires source content that is not lawfully available for the required use. Bibliographic metadata, factual catalogue identifiers, independently created observations, and public-domain/licensed evidence should continue to be exploited where lawful.

## Human-review boundary

Independent review is not a rights issue and cannot be simulated by AI. The pre-expert target is therefore: **all non-rights, non-expert work exhausted; remaining expert decisions isolated into bounded review questions with complete evidence packets.**
