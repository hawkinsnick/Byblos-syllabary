# Attribution and rights

Attribution and permission are separate questions. This repository publishes
bibliographic facts and original attributed notes; it does not republish third-party
transcription datasets, papers, plates, photographs or fonts in this snapshot.

Source register records scope-specific rights observations. A licence on the BAF
abstract cannot be transferred to OCBI. OCBI's font permission is not a corpus
permission. Wikimedia's spatula-e redraw is a derivative with added interpretations
and must not be relabelled an artifact photograph.

## Admission of future assets

Record creator, exact source URL, source version or checksum, licence or written
permission reference, licence URL, permitted use, modifications and required credit.
For an imported sequence also record the encoding map and each editorial change.
Keep original and normalized sequences separately. Do not silently transfer
licences across different media from one source.

## What can be reused now

Software written for this project is MIT licensed (see LICENSE-CODE).
Factual metadata and original annotations retain their explicit citations.
No project-wide data licence is asserted yet. Third-party material keeps its
own rights. A public GitHub repository is not proof of permission.
